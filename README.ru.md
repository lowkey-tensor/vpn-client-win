# VPN-клиент для Windows

[English](README.md) · **Русский**

Лёгкий клиент в стиле Happ / Hiddify: вставил ссылку или подписку, нажал одну кнопку. Работает на ядрах
[sing-box](https://github.com/SagerNet/sing-box) и [Xray-core](https://github.com/XTLS/Xray-core).

## Установка

1. Скачайте последний архив `VpnClient-*-win-x64.zip` на странице **Releases** и распакуйте в любую папку.
2. Запустите `VpnClient.exe` и подтвердите запрос прав администратора (нужны для режима TUN и автозапуска).
3. Вставьте ссылку на узел или подписку в поле сверху, нажмите `+`, выберите узел и нажмите большую круглую кнопку.

Windows может показать «Windows защитила ваш компьютер» — программа не подписана цифровой подписью.
Нажмите **Подробнее → Выполнить в любом случае**. Установка .NET не нужна, ядра уже в архиве (папка `core`).

**Разблокируйте архив до распаковки:** правая кнопка на `.zip` → *Свойства* → поставьте галочку **Разблокировать** → OK. Иначе Windows
пометит все распакованные файлы (и ядра) как скачанные из интернета, и SmartScreen или антивирус могут не дать их запустить.

## Поддерживаемые протоколы

| Протокол | Ссылка | Особенности |
|---|---|---|
| VLESS | `vless://` | Reality, TLS, Vision; транспорты tcp / ws / grpc / h2 / httpupgrade; **VLESS-шифрование (mlkem) и XHTTP** через Xray |
| VMess | `vmess://` | форматы v2rayN (base64 JSON), `vmess://uuid@host`, Shadowrocket |
| Trojan | `trojan://` | TLS, Reality, ws / grpc |
| Shadowsocks | `ss://` | SIP002 и старый формат, SS-2022, плагины obfs-local и v2ray-plugin |
| TUIC | `tuic://` | v5 |
| Hysteria 2 | `hysteria2://`, `hy2://` | obfs salamander, port hopping |
| Hysteria | `hysteria://` | v1 (udp) |
| AnyTLS | `anytls://` | |
| SOCKS5 | `socks://`, `socks5://` | с логином и без |

Не поддерживаются: WireGuard (ссылкой), mKCP, Shadowsocks с shadow-tls. Клиент напишет понятную причину в журнале.
Все протоколы проверены сквозным тестом на локальных серверах (каждая ссылка → конфиг → соединение).

## Возможности

- Режимы: **системный прокси** и **TUN** (весь трафик компьютера).
- Импорт: ссылки, подписки (обычный текст и base64), QR-код конфига для телефона.
- Российские сайты напрямую (Ozon, банки, Госуслуги не видят VPN) — переключатель.
- Блокировка рекламы и трекеров на уровне DNS.
- Раздельный туннель в окне **«Маршруты»**: впишите сайт (подойдёт и ссылка целиком, IP или подсеть) и нажмите **«Напрямую»**
  или **«Через VPN»**; правило можно переключить или удалить в один клик, весь список копируется и вставляется на другом компьютере.
  Программы: «мимо VPN» или (TUN, экспериментально) «только выбранные программы через VPN».
- Скорость и трафик; **отклик через VPN** (реальный HTTP-запрос) и пинг до сервера показываются отдельно.
- Маленькие экраны: окно подгоняется под рабочую область (от 1366×768), при нехватке места прокручивается и помнит размер и положение.
- Понятные ошибки запуска: если Windows или антивирус блокирует ядро, клиент пишет причину и что делать, а не голый код ошибки.
- **«Скопировать отчёт»** и **«Сообщить о проблеме»** (раздел «Журнал и поддержка»): отчёт без личных данных (адресов, ссылок,
  имён узлов, имени пользователя) копируется в буфер обмена.
- Автовосстановление: переподключение, смена узла, реакция на сон/пробуждение.
- Автозапуск при входе в Windows (задача Планировщика с правами администратора, без окна UAC), работа в трее.
- Для VLESS через Xray включено мультиплексирование (mux): десятки соединений приложения идут по нескольким
  TCP-соединениям к серверу. Без него серверы и провайдеры, ограничивающие число новых соединений, «подвешивают»
  большую часть запросов в режиме TUN.
- Журнал в файл (`%APPDATA%\VpnClient\logs`, хранится 7 дней).

## Если не подключается

Сначала раскройте **«Журнал и поддержка»** внизу окна: причина написана там.

| Что видите | Вероятная причина и что делать |
|---|---|
| Красная плашка «Программа не может запустить ядро» | Антивирус или Windows удалили/заблокировали `core\sing-box.exe` или `core\xray.exe`. Добавьте папку программы в исключения антивируса, разблокируйте архив (см. «Установка») и распакуйте заново. |
| Ошибка 225 / 226 | Антивирус принял ядро за вирус. То же самое. |
| Ошибка 5 (отказано в доступе) | Папка защищена («Контролируемый доступ к папкам», политика организации) или файл заблокирован. Перенесите программу, например, в `C:\Tools\Vpn`. |
| Подключилось, но ничего не грузится, пинг около 1000 мс | Одновременно работает другой VPN или прокси (Happ, Hiddify, Zapret, расширение браузера) — закройте его. Попробуйте другой режим (прокси ↔ TUN) и другой узел. |
| В TUN работают не все сайты | Посмотрите **отклик через VPN**. Если он большой — сервер или провайдер ограничивает новые соединения: возьмите узел с мультиплексированием (VLESS через Xray) или другой сервер. |
| Сайт, который должен открываться напрямую, не открывается | **«Маршруты»** → добавьте его кнопкой **«Напрямую»** → **«Сохранить и переподключить»**. |

Если не помогло — нажмите **«Сообщить о проблеме»**: откроется страница, а отчёт (без личных данных) уже будет в буфере обмена — просто вставьте его.
## Сборка из исходников

Нужны [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и Windows 10/11 x64.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\fetch-core.ps1   # ядра в core\ (проверка SHA256)
dotnet build src\VpnClient -c Release -o app
app\VpnClient.exe
```

Автономный архив (без установки .NET у пользователя):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package.ps1 -Version 4.4
```

## Где хранятся данные

`%APPDATA%\VpnClient\state.dat` — список узлов и настройки, зашифровано средствами Windows (DPAPI, доступно
только вашей учётной записи). Временные конфиги с ключами стираются через 3 секунды после старта ядра.
Ключи и ссылки в репозиторий не попадают (`.gitignore`).
Переменная окружения `VPNCLIENT_DATA_DIR` переносит данные, журналы и временные конфиги в другую папку (тесты, портативный запуск).

## Удаление

Закройте клиент (значок в трее → «Выход»), выключите «Автозапуск» в настройках и удалите папку с программой.
Данные: `%APPDATA%\VpnClient`.

## Телефон

В папке `mobile/` лежат готовые правила для Shadowrocket (iOS) с теми же настройками, что в клиенте.

## Ядра и сторонние лицензии

Бинарники sing-box и Xray-core в репозиторий не включены: их скачивает `scripts/fetch-core.ps1` с официальных релизов.

Программа предоставляется «как есть», без гарантий.
